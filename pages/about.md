This is the **official library of the Open Knowledge project** — and it is
also its own best demonstration: everything you are reading is served by an
Open Knowledge instance running in *static content mode*, straight from a
public git repository, with no database and no server state.

Open Knowledge is an open-source application, released under the MIT
license, that lets anyone publish curated knowledge as beautiful, studiable
courses — openly, and as a gift. It collects no personal data from its
visitors, and learning here requires no account of any kind.

The courses in this library explain the project itself: the long tradition
of giving knowledge away that it belongs to, how the application works, and
how to deploy your own library.

Open Knowledge is an open-source project:
[github.com/oegea/open-knowledge](https://github.com/oegea/open-knowledge).
The content of this very site lives at
[github.com/oegea/open-library](https://github.com/oegea/open-library).
