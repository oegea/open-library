Welcome. This site is the official library of the Open Knowledge project,
and it practices what it preaches: it runs in **static content mode**, which
means everything you see — courses, news, pages, this very post — lives as
plain Markdown and JSON files in a
[public git repository](https://github.com/oegea/open-library), rendered by
a stateless Open Knowledge instance. There is no database behind this page.
Publishing here is a `git push`.

Use it as a reference: fork the content repository, look at how a course is
structured, and start your own library from the same bones. The course
*Running Open Knowledge* in this catalog walks through every step.
